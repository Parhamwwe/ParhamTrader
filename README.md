# Toobit Signal Bot → تلگرام

این ربات هر ۱۵ دقیقه (روی تایم‌فریم‌های 15m، 1h، 4h) قیمت چندین رمزارز رو
از Toobit می‌گیره، همون منطق استراتژی Trend + RSI + MACD + ADX + MTF + Volume
رو روش اجرا می‌کنه، و اگه سیگنال BUY یا SELL پیدا بشه، به تلگرام پیام می‌فرسته.
کاملاً رایگانه و روی GitHub Actions اجرا می‌شه — نیازی به روشن بودن کامپیوتر
خودت نداره.

## مرحله ۱: ساخت بات تلگرام

1. توی تلگرام دنبال `@BotFather` بگرد و بهش پیام بده
2. دستور `/newbot` رو بفرست
3. یه اسم و یوزرنیم برای بات انتخاب کن (یوزرنیم باید به `bot` ختم بشه)
4. یه **توکن** بهت می‌ده، شبیه `123456789:AAExxxxxxxxxxxxxxxxxxxxxxx` — نگهش دار

## مرحله ۲: پیدا کردن Chat ID خودت

1. به بات جدیدی که ساختی یه پیام بفرست (مثلاً بنویس `سلام`)
2. توی مرورگر این آدرس رو باز کن (به‌جای `<TOKEN>` توکن خودت رو بذار):
   `https://api.telegram.org/bot<TOKEN>/getUpdates`
3. توی خروجی JSON دنبال `"chat":{"id":` بگرد — همون عدد، Chat ID توئه

## مرحله ۳: ساخت ریپازیتوری روی GitHub

1. وارد github.com بشو (اگه اکانت نداری، رایگان بساز)
2. یه ریپازیتوری جدید بساز (Private بودنش پیشنهاد می‌شه چون توکن‌های حساس داری)
3. فایل‌های این پوشه (`signal_bot.py`, `requirements.txt`, `state.json`,
   `.github/workflows/signal-bot.yml`) رو توی همون ریپازیتوری آپلود کن
   (از دکمه "Add file → Upload files" توی صفحه گیت‌هاب استفاده کن)

## مرحله ۴: اضافه کردن توکن‌ها به‌عنوان Secret

1. توی ریپازیتوری، برو به Settings → Secrets and variables → Actions
2. روی "New repository secret" بزن و دوتا Secret بساز:
   - نام: `TELEGRAM_BOT_TOKEN` — مقدار: همون توکنی که از BotFather گرفتی
   - نام: `TELEGRAM_CHAT_ID` — مقدار: همون Chat ID که پیدا کردی

## مرحله ۵: فعال کردن و تست

1. برو به تب **Actions** توی ریپازیتوری
2. اگه پیام "Workflows aren't being run on this forked repository" یا مشابهش
   دیدی، روی "I understand my workflows, go ahead and enable them" بزن
3. روی workflow با اسم "Toobit Signal Bot" کلیک کن، بعد "Run workflow" رو
   بزن تا یه بار دستی اجراش کنی و مطمئن بشی درست کار می‌کنه
4. اگه سیگنالی موجود بود، باید توی چند ثانیه پیامش رو توی تلگرام ببینی

بعد از این، خودش هر ۱۵ دقیقه اجرا می‌شه — دیگه نیازی به کار دستی نیست.

## تغییر لیست کوین‌ها یا پارامترها

توی فایل `signal_bot.py`، بالای فایل لیست `SYMBOLS` و پارامترهای استراتژی
(مثل `RSI_OVERSOLD`, `ADX_THRESHOLD` و...) رو می‌تونی ویرایش کنی. بعد از هر
تغییر، فایل رو دوباره توی گیت‌هاب آپلود/ذخیره کن.

## نکات مهم

- تایم‌فریم 5 دقیقه عمداً حذف شده چون زمان‌بندی GitHub Actions برای بازه‌های
  خیلی کوتاه قابل‌اعتماد نیست (ممکنه چند دقیقه تاخیر بخوره).
- این ربات هیچ معامله‌ای برات باز نمی‌کنه — فقط پیام می‌فرسته. تصمیم و اجرای
  معامله دست خودته.
- فایل `state.json` برای جلوگیری از پیام تکراری روی هر کندله؛ دستش نزن.
